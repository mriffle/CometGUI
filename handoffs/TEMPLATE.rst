What was built
==============

Where the code lives, what it does, and the shape of the main types. Enough
that the next agent does not have to reverse-engineer the design from the
source.

==========

   * - 1

What is incomplete and why
==========================

Be specific. "Mostly done" is not a state. Name the file, the missing
behaviour and what it would take.

Decisions encountered
=====================

Any ``D-`` item hit, and any smaller judgement call made that a later phase
could reasonably have made differently.

Surprises
=========

Things that were not true of the world as the specification described it.
These are the most valuable part of a handoff.

First thing the next agent should do
====================================

One concrete action.
