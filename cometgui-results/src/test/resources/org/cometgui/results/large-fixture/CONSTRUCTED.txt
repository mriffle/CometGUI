LARGE PERFORMANCE FIXTURE -- CONSTRUCTED, synthetic, NOT produced by Percolator
==============================================================================

Phase 10 unit 1, 2026-10-08; design decision P10-2 in
handoffs/PHASE-10-worklog.rst; R-RES-03 ("a performance fixture large enough
to cross the threshold shall exist before the results UI is built").

What it is
  A synthetic, Percolator-SHAPED target PSM table and target peptide table,
  written by a deterministic, standard-library-only Python generator. No
  spectrum, search or real dataset is involved: peptides are random sequences
  over the twenty amino acids (some with M[15.9949]), flanked as Percolator
  writes them (K.PEPTIDE.R); protein accessions are synthetic
  (fx|FX0001234|SYN0001234_FIXTURE), deliberately not UniProt's form (D-006
  spirit). The data is never committed: it is written to the gitignored
  scratch/phase10/large/ and remade by the command below.

Command (from the repository root)
  python3 scripts/fixtures/large-results-fixture.py
  python3 scripts/fixtures/large-results-fixture.py --self-check
  Defaults: --psm-rows 1000000 --peptide-rows 400000 --seed 20261008
  --out scratch/phase10/large. Generator version 1.0.0. Written with
  Python 3.11.2 in 13.7 s; the self-check takes about 20 s.

Shape
  Header: PSMId score q-value posterior_error_prob peptide proteinIds.
  Rows ordered by descending score; known q-values ascend with the row, as
  Percolator's do; unknown ones sit at drawn positions among them.
  proteinIds continues to the end of the row: psms.tsv 819857 rows with one
  protein, 100106 with two, 50202 with three, 29835 with four.
  PSMId is Comet's SpecId, <-N base>_<scan>_<charge>_<rank>, with four bases:
    /fixture/runs/run-01/outputs/comet/sample_A
    /fixture/runs/run-01/outputs/comet/sample_B
    /fixture/runs/run-01/outputs/comet/2026_10_08_sample_C_2_1   (digits and
        underscores of its own, so a PSMId must be split from the right)
    /fixture/runs/run-01/outputs/comet/sample D                 (a space)
  250000 psms.tsv rows and 100000 peptides.tsv rows each.
  Q-values are written as Percolator writes them, C %g with six significant
  digits (46290 psms.tsv q-values in exponent form, e.g. 9.27998e-07).

  was not taken from the Java.
