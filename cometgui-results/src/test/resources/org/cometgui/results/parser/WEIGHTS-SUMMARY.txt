LEARNED FEATURE WEIGHTS SUMMARY -- expected values computed independently
=========================================================================

Phase 10 unit 4, 2026-10-08. Gate item 7 (AC-RES-09) at the model level and
design decision P10-3: the numbers WeightsSummaryIndependentTest pins were
printed by the Python program below -- not by Java -- run once per file with
Python 3.11.2 on 2026-10-08 from the repository root, and typed into the test
mechanically from its output. The program shares nothing with
org.cometgui.results.parser: it splits the file itself, reads every value as
an exact fractions.Fraction, takes the mean, mean absolute value and
population variance (divide by n) exactly, the square root in decimal at 60
digits, counts signs by exact comparison with 0 (so -0.0000 is zero), ranks
the non-m0 features by exact comparison of mean absolute value (competition
ranking: 1 + the number strictly greater; m0 unranked), and prints each value
as the double nearest the exact result (%.17g).

Command, verbatim (FILE is the weights file):

python3 - FILE <<'PY'
import sys
from decimal import Decimal, getcontext
from fractions import Fraction

getcontext().prec = 60
data = [l.rstrip("\r\n") for l in open(sys.argv[1], encoding="utf-8")]
data = [l for l in data if not l.startswith("#")]
assert len(data) % 3 == 0 and data, "not whole splits"
groups = [data[i:i + 3] for i in range(0, len(data), 3)]
names = groups[0][0].split("\t")
assert all(g[0].split("\t") == names for g in groups)
norm = [[Fraction(v) for v in g[1].split("\t")] for g in groups]
n = len(groups)
print("splits", n)
rows = []
for j, name in enumerate(names):
    w = [s[j] for s in norm]
    mean = sum(w) / n
    mabs = sum(abs(x) for x in w) / n
    var = sum((x - mean) ** 2 for x in w) / n
    sd = (Decimal(var.numerator) / Decimal(var.denominator)).sqrt()
    pos = sum(1 for x in w if x > 0)
    neg = sum(1 for x in w if x < 0)
    zero = n - pos - neg
    sign = ("ALL_POSITIVE" if pos == n else "ALL_NEGATIVE" if neg == n
            else "ALL_ZERO" if zero == n else "MIXED")
    rows.append([name, w, mean, mabs, sd, pos, neg, zero, sign])
ranked = [r for r in rows if r[0] != "m0"]
for r in rows:
    rank = "-" if r[0] == "m0" else str(1 + sum(1 for o in ranked if o[3] > r[3]))
    print("\t".join([r[0], rank, r[8], "%d/%d/%d" % (r[5], r[6], r[7]),
                     "%.17g" % float(r[2]), "%.17g" % float(r[3]), "%.17g" % float(r[4]),
                     ",".join("%.17g" % float(x) for x in r[1])]))
PY

Output columns: feature, rank ("-" = the bias m0, not ranked), sign verdict,
positive/negative/zero split counts, mean signed, mean absolute, population
standard deviation, then the normalised weight of each split. The test
compares mean, mean absolute and deviation within 1e-12 absolute (the class
comment says why) and everything else exactly.
