REAL K562 PERCOLATOR OUTPUT -- provenance and numbers only, NOT the data
=========================================================================

D-006: CometGUI does not redistribute spectrum or FASTA data, so the
Percolator output of a search over them is never committed either. The files
this record describes stay in the gitignored scratch/ directory; this file
holds only where they came from, their digests and counts taken from them.
org.cometgui.results.testing.RealK562 pins the same digests and counts, and
RealK562Test fails (never skips) when a file is missing or differs.

Shape, checked with awk on 2026-10-08
  Header of all eight tables: PSMId score q-value posterior_error_prob
  peptide proteinIds, tab-separated, LF line endings, final newline.
  Rows carry 6 to 16 fields (proteinIds continues to the end of the row):
  psms.target 3596 rows of 6 fields, 301 of 7..16.
  q-value column: every field is a plain decimal (none empty, none
  non-numeric, none outside [0, 1], none in exponent form -- PEP has
  exponent forms, q-value does not); none equals 0, 0.005, 0.01, 0.05 or 1
  exactly. Minimum q: 0.00112905 (psms.target), 0.00198145 (psms.decoy),
  0.00185428 (peptides.target), 0.00334231 (peptides.decoy); maximum 0.680615,
  0.680788, 0.759875, 0.759875. 3.07.1 and 3.09 agree on every count below.

Counts. Command (mawk 1.3.4 20200120), run once per file and cutoff c:

  LC_ALL=C awk -F'\t' -v c="$c" 'NR>1 { t++; q=$3;
    if (q !~ /^[+-]?([0-9]+(\.[0-9]*)?|\.[0-9]+)([eE][+-]?[0-9]+)?$/ || q+0 < 0 || q+0 > 1) u++;
    else if (q+0 <= c+0) p++; else f++ }
    END { printf "%d %d %d %d\n", t, p, f, u }' "$file"

  printing total, passing (q <= c, inclusive), failing, unknown. The regular
  expression keeps awk honest: mawk's $3+0 reads "nan", "inf" and "0,005" as
  numbers, so a bare 'NR>1 && $3+0<=0.01' over the constructed
  parser/constructed/psms-unknown-q.tsv counts 10 passing rows where there are
  5; this command gives 15 5 2 8 there, the hand count in CONSTRUCTED.txt.
